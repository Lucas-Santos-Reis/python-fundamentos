📊 Automatizador de Planilhas com Python

Este projeto consiste em um script em Python para automatizar a leitura, organização e consolidação de dados a partir de múltiplos arquivos Excel ou CSV.

🚀 Funcionalidades

Leitura automática de vários arquivos em uma pasta

Padronização de colunas

Limpeza de dados inconsistentes

Consolidação em um único arquivo final

Exportação para Excel ou CSV

🛠️ Tecnologias utilizadas

Python

OpenPyXL

🎯 Aplicações práticas

Relatórios administrativos

Controle financeiro

Consolidação de dados operacionais

Automatização de rotinas manuais

▶️ Como executar

Clone o repositório

Instale as dependências

Coloque os arquivos na pasta /dados

Execute o script principal
