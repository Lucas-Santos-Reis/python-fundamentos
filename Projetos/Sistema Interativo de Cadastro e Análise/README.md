# Sistema Interativo de Cadastro e Análise

Projeto desenvolvido em Python com o objetivo de praticar
fundamentos da linguagem, como:
- Listas e dicionários
- Estruturas condicionais
- Laços de repetição
- Funções
- Entrada e saída de dados no terminal

## Funcionalidades
- Cadastro de pessoas (nome, idade e profissão)
- Listagem de pessoas cadastradas
- Cálculo da idade média
- Identificação da profissão mais comum
- Contagem de pessoas maiores de idade

## Estrutura do projeto
- `projeto2.py`: código principal do sistema
- `projeto2.1.py` código aprimorado
